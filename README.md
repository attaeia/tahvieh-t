# ابزار فروش پایش الکترونیک - ورژن ۴.۱.۱

سه بخش: تهویه سالن، کابل، پیش‌فاکتور (PDF، اکسل، لیست تجهیزات).

## آپلود در گیت‌هاب (GitHub Pages)
1. یک مخزن (repository) بساز.
2. همه‌ی فایل‌های همین پوشه را آپلود کن (index.html در ریشه باشد).
3. Settings ← Pages ← Source: Deploy from a branch ← main / (root) ← Save.
4. چند دقیقه بعد آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود.

نکته: اکسل و PDF از کتابخانه‌های cdnjs استفاده می‌کنند؛ بار اول باید اینترنت وصل باشد، بعد از آن در حالت آفلاین هم کار می‌کند.
