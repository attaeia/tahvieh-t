پایش الکترونیک — نسخه آزمایشی 11.61 (مرحله اول انتقال به IndexedDB)

این بسته بر اساس نسخه 11.60.111 ساخته شده و ظاهر برنامه را تغییر نمی‌دهد.

چه کاری انجام شده است؟
- اضافه شدن فایل payesh-storage.js و دیتابیس payesh-crm-db با Object Store به نام legacyKV.
- تهیه نسخه مستقل در IndexedDB از کلیدهای اطلاعاتی حساب‌های موجود در LocalStorage، بدون پاک کردن منبع اصلی.
- هر تغییر یا حذف موفق در LocalStorage در IndexedDB هم منعکس می‌شود.
- داده‌های حساب‌های مختلف با کلیدهای payesh-u-<account>::... از هم جدا می‌مانند.
- کلیدهای احراز هویت و همگام‌سازی (شامل تنظیمات احتمالی GitHub) عمداً وارد این نسخه پشتیبان نمی‌شوند.
- نسخه Service Worker به payesh-v11-61-0 افزایش یافته و فایل جدید به کش آفلاین افزوده شده است.
- قرارداد فعلی همگام‌سازی GitHub بدون تغییر مانده است.

محدودیت مهم:
این مرحله هنوز IndexedDB را به مخزن اصلی و یگانه تبدیل نمی‌کند؛ LocalStorage همچنان در مسیر اصلی برنامه و GitHub Sync استفاده می‌شود. بنابراین محدودیت حجمی LocalStorage و نیاز به بازنویسی آرایه‌های بزرگ هنوز رفع نشده‌اند. افزایش سرعت تضمین نمی‌شود. این مرحله برای مهاجرت کم‌خطر و بازیابی داده است.

پیش از نصب:
1. از نسخه فعلی برنامه و داده‌های هر حساب یک نسخه پشتیبان مجزا تهیه کنید.
2. نسخه را ابتدا روی محیط آزمایشی با Origin جداگانه اجرا کنید.
3. از استقرار هم‌زمان نسخه قدیمی و جدید روی اطلاعات مشترک خودداری کنید.
4. پس از تست حساب‌ها، ساخت مشتری، تماس، پیش‌فاکتور، بازیابی، و GitHub Sync، برای انتشار تصمیم بگیرید.
5. به دلیل اطلاعات واقعی مشتریان و توکن‌ها، فایل پشتیبان را در محل امن نگهداری کنید.

دسترسی فنی در Console مرورگر (F12):
await PayeshStorage.status()
await PayeshStorage.previewRestore()  // فقط حساب فعال
await PayeshStorage.exportBackup()    // دریافت نسخه JSON شامل تمام حساب‌ها؛ محرمانه
await PayeshStorage.restoreMissingForCurrentUser() // فقط کلیدهای مفقود حساب فعال را پر می‌کند، سپس صفحه را بازخوانی کنید.

توجه: هیچ داده‌ای به‌طور خودکار از IndexedDB بر روی LocalStorage بازنویسی نمی‌شود.
حذف Cache/Storage مرورگر ممکن است هر دو مخزن را پاک کند؛ داشتن نسخه پشتیبان خارج از مرورگر الزامی است.

باقیمانده برای انتقال کامل در نسخه‌های بعدی:
- تبدیل تمام کدهای ذخیره‌سازی به Repository غیرهم‌زمان.
- رکوردی کردن آرایه‌های بزرگ مشتریان، تماس و سرنخ‌ها و ایجاد Indexها.
- تغییر GitHub Sync برای خواندن/نوشتن مستقیم از IndexedDB و مدیریت تعارض و تغییر دستگاه‌ها.
- بازطراحی سیاست محرمانگی حساب‌ها و ذخیره‌سازی رمز عبور خام در نسخه مبنا.
- تست واقعی در Chrome، Edge، موبایل، آفلاین و حساب‌های چندکاربره.

این نسخه برای استفاده عملیاتی بدون آزمون مستقل توصیه نمی‌شود.
