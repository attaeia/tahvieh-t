ابزار فروش پایش الکترونیک - ورژن ۶ (بسته‌ی کامل برای گیت‌هاب پیجز)

فایل‌ها:
- index.html: خود اپ (همه‌ی قابلیت‌ها)
- manifest.webmanifest و icon-*.png و apple-touch-icon.png: برای نصب روی گوشی (PWA)
- sw.js: برای کارکردن بدون اینترنت

آپلود:
1) وارد مخزن پیجز خودت شو (باید دسترسی نوشتن داشته باشی).
2) Add file ← Upload files، همه‌ی فایل‌های داخل این زیپ را (نه خود زیپ را) بکش و Commit changes بزن.
   فایل‌های هم‌نام (index.html و ...) جایگزین قبلی‌ها می‌شوند.
3) یکی دو دقیقه صبر کن تا پیجز ساخته شود.
4) اپ را باز کن و دو بار رفرش کن. بالای داشبورد باید «ورژن ۶» نوشته باشد.
5) روی گوشی: از منوی مرورگر Add to Home Screen (افزودن به صفحه‌ی اصلی).

همگام‌سازی گیت‌هاب: داشبورد ← «همگام‌سازی با گیت‌هاب». مخزن داده باید خصوصی و جدا از مخزن پیجز باشد.

برای آپدیت‌های بعدی: فقط index.html را جایگزین کن. اگر نسخه‌ی قدیمی دیدی،
عدد نسخه‌ی V را در sw.js بالا ببر (مثلاً payesh-v6-2).
